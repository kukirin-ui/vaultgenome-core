# Command-line reference

Generated by `scripts/gen_cli_reference.sh` (`make cli-reference`) from the
usage text each binary prints for `help` / `-h`. The four release binaries
are `sagvd`, `acp-compute`, `acpctl` and `acp-bootstrap`; `acp-demo` is a
development aid and is not released. Configuration files, bundle formats and
the audit schema are described in `docs/operator/` and `docs/spec/`.

## sagvd

```text
sagvd — Secure AI Genome Vault Daemon (authority / vault)

Usage:
  sagvd -config PATH
  sagvd identity -config PATH
  sagvd crosscloud-restore -config PATH -decision-id ID -destination-kind KIND \
        -destination-endpoint URL {-key-file KID:PATH | -key-escrow ENVELOPE}... [-session-id ID] [-manifest-id ID]
  sagvd crosscloud-confirm -config PATH -decision-id ID -destination-endpoint URL \
        {-bundle PATH | -key-id KID} [-require-gate EQUIVALENT|EXACT] [-wait DURATION]
  sagvd failover -config PATH -policy POLICY.json -outbox DIR [-poll 2s] [-confirm-wait 15m] [-report PATH]
  sagvd escrow-provision -config PATH -out SEALED -pub PUBLIC.pem [-recovery-to RECOVERY.pem -recovery-out ENVELOPE] [-stdin]
  sagvd seal-keys -config PATH
  sagvd version
  sagvd help

Description:
  Authority daemon. Binds the Return Path listener for
  acp-compute workers and the operator REST API for job
  submission (POST /v1/jobs) and lookup (GET /v1/jobs/{id}).

  identity prints the authority signing key and TEE identity other
  hosts pin, as JSON. crosscloud-restore releases DEKs to an attested,
  allow-listed acp-bootstrap destination (docs/operator/06_cross_cloud_restore.md);
  crosscloud-confirm records its restore once the destination's TEE-signed
  receipt checks out against that release (ADR 0011). failover carries out
  the operator's signed failover policy: when the primary's sentinel reports
  a compromise or its heartbeat stops, it releases the last trustworthy
  genome's escrowed key to the standby the policy names and confirms the
  restore (ADR 0012). escrow-provision makes the authority's escrow key
  inside this process and writes it sealed to this host's TEE, never in
  the clear; with -recovery-to it also wraps the key to the operator's
  recovery key, and -stdin re-seals a recovered key on a new host (ADR 0016).

Flags:
  -config PATH   JSON config file; see cmd/sagvd/doc.go for schema.
```

## acp-compute

```text
acp-compute — external compute worker (delegated, non-authority)

Usage:
  acp-compute -config PATH
  acp-compute identity -config PATH
  acp-compute seal-keys -config PATH
  acp-compute version
  acp-compute help

Description:
  Long-lived worker daemon. Dials sagvd over the Return Path,
  serves one gate job per session, then reconnects.

  identity prints what sagvd pins for this worker — its signing key,
  its TEE provider and launch measurement — as JSON.

Flags:
  -config PATH   JSON config file; see cmd/acp-compute/doc.go for schema.
```

## acpctl

```text
acpctl — AI Continuity Platform administrative CLI

Usage:
  acpctl <command> [flags]

Commands:
  version       Print the build version and exit
  help          Print this message
  recover       Restore a sealed vault inside a fresh TEE
  status        Print a read-only summary of the audit log
  audit query   List events filtered by kind / session / time
  audit verify  Replay the audit chain and verify hashes + signatures
  lineage       Trace events tied to a session or manifest ID
  genome seal   Seal a model or directory into a bundle; its key goes to --key-out
  genome open   Restore a bundle with its --key-file, all or nothing (alias: rewind)
  genome verify Check a bundle (and, with --restored, a restored tree) against its seal
  genome inspect Print a bundle's header without its key
  genome chain  Validate the lineage of a directory of bundles
  stop keygen   Create the operator key that signs stop lists
  stop issue    Sign a list that stops all key releases or revokes destinations
  stop verify   Check a stop list against the operator public key
  escrow keygen Create a plaintext escrow key pair (simulated TEE only; hardware: sagvd escrow-provision)
  escrow recovery-keygen  Create the operator's recovery key the sealed escrow key is wrapped to
  escrow recover          Open a recovery envelope; pipe the key into sagvd escrow-provision -stdin
  sentinel keygen  Create the sentinel's signing key
  sentinel identity  Print the primary TEE's identity for the operator to pin
  sentinel seal-key  Seal the sentinel's seed file in place to the primary's TEE
  sentinel watch   Keep a running model's state sealed; report when a tripwire fires
  failover issue   Sign the operator's failover policy: which standby, on which signs of failure
  failover verify  Check a failover policy against the operator public key

Run `acpctl <command> --help` for per-subcommand flags.
```

## acp-bootstrap

```text
acp-bootstrap 0.0.0-dev — destination daemon for Phase 4 cross-cloud restore

USAGE
    acp-bootstrap -config /path/to/config.json
    acp-bootstrap identity -config /path/to/config.json
    acp-bootstrap seal-keys -config /path/to/config.json
    acp-bootstrap version
    acp-bootstrap help

    identity prints, as JSON, what the source operator pins for this
    destination: TEE provider, measurement, and (simulated backend) the
    attestation public key. It opens no listener.

CONFIG FORMAT
    JSON file with sections: http, tee, source_authority, genome, health, log.
    See cmd/acp-bootstrap/config.go for the full schema.

ENDPOINTS
    POST /v1/crosscloud/handshake — answer a signed handshake with a fresh
                                    X25519 key and Evidence that binds it
    POST /v1/crosscloud/token     — accept a signed key-release token whose
                                    DEKs are encapsulated to that key
    GET  /v1/genome/restores      — (genome section) every released
                                    genome's restore and where it stands
    GET  /v1/genome/receipt?key_id=ID
                                  — a completed restore's receipt, signed
                                    with this TEE's Evidence

REFERENCES
    ADR 0006 — Cross-Cloud KMS-Mediated Restore
    ADR 0009 — X25519 KEM for cross-cloud DEK delivery
    docs/operator/06_cross_cloud_restore.md
```
